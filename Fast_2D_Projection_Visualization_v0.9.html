Projection method — The electron scattering factor of each atom is parameterized as a sum of 5 Gaussians using Peng 1996 tabulated coefficients (Acta Cryst. A52, 257–276, Table 1; all elements Z = 1–98): f(s) = Σᵢ aᵢ exp(−bᵢ s²), where s = sinθ/λ (Å⁻¹) is the Peng scattering parameter (= 1/(2d) for Bragg spacing d), aᵢ (Å) and bᵢ (Å²) are element-specific coefficients fit to electron diffraction data. The 2D projected density per atom is obtained analytically from the 2D inverse Fourier transform of each Gaussian slice (projection-slice theorem): φᵢ(ρ) = (π aᵢ / bi) exp(−π²ρ² / bi), where ρ is the 2D radial distance from the atom centre. Box Grid sets the canvas pixel resolution (128–512 px); larger grids give sharper images at the cost of compute time. Box Size controls the field of view as a multiple of the longest molecular dimension.
